# Placement Suite

Unified platform: Job Intelligence, JD Analyzer, Resume Builder, Application Tracker, and Central Readiness Score.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Routes

- `/` — Landing
- `/jobs` — Job Intelligence
- `/analyze` — JD Analyzer
- `/resume` — Resume Builder
- `/applications` — Application Pipeline
- `/dashboard` — Unified Dashboard
- `/settings` — Settings
- `/proof` — Proof
